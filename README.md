# oneliner-five-seconds-glass

## Entry

Five seconds after the crash, the cat's official statement: the glass had
been flashing the reflection of a second, handsomer cat all morning, and
this house holds exactly one cat.

`main.ts` writes it to `/output/entry.txt`:

> That glass kept reflecting a much handsomer cat, and I refuse to share this house with an impostor.

## How to run

    node main.ts

The entry lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, otherwise in `/output/entry.txt`.

## Note

No apology, no confession — just a cat defending its territory.
